# Next Step · 作品集视觉 Demo

打开 [`demo/index.html`](index.html)（直接用浏览器打开，或在仓库根目录运行 `python3 -m http.server` 后访问 `/demo/`）。

这是一个 **流程 + 风格** 的样板，不是成品：8 个项目只放了关键事实，用来检验每种视觉世界承载真实内容时的样子。

## 核心概念

你的所有项目都在回答同一个问题：**当信息不确定、界面挡路、或日常流程被打断时，人如何走出下一步？**
所以作品集本身也被设计成“会解释自己、会被打断再恢复”的界面：

| 机制 | 来源 | 作用 |
| --- | --- | --- |
| **中断式开场** | Remembering in Motion | 加载到 62% 时故意“中断”，然后显示 “where was I?” 并恢复。三秒内讲清你的主题。 |
| **WHY 面板** | Wildling 的 MIND 面板 | 左下角常驻，实时说明当前页面考虑过哪些布局、最后选了哪个、为什么。 |
| **旅程轨道** | Transfer Coach 的行程进度 | 右侧显示 Boot → Hero → Work → Case → Process → Contact，可点击跳转。 |
| **“尚未证明”章节** | 各仓库的 honest scope 习惯 | 每个案例最后一章写清楚哪些结论还没验证。 |

## Demo 流程

`00 Boot` 中断与恢复 → `01 Hero` → `02 Work` 项目索引 → `03 Case` 案例（从点击位置圆形展开，←/→ 切换，Esc 关闭）→ `04 Process` 四步方法 → `05 Contact` 磁吸按钮。

## v2 · Motion Studies（[`demo/v2/index.html`](v2/index.html)）

方向：保留 David Heckhoff 的空间感和镜头运动，以及 Jason Yuan 的编辑式项目排版，但改用明亮、克制的材质。配色保持安静，把冲击力集中在动效上。需要用本地服务器打开（`python3 -m http.server`，然后访问 `/demo/v2/`），粒子取色需要同源图片。

| 方案 | 参考 | 关键体验 |
| --- | --- | --- |
| **A Gallery** | Heckhoff · 空间 | 滚动驱动镜头穿过一条白色画廊长廊，作品挂在左右交错的展板上，镜头随之蛇形移动并有远景雾化。点击展板，图片从 3D 空间飞出，变成案例封面。 |
| **B Studio** | Heckhoff · 物件 | 实时 3D 转台上放着 8 个抽象雕塑，每个对应一个项目：圆环、卵石、黑胶、路线丝带、声波柱、罐子、断开的环加一颗蓝球、柱状图。可拖拽旋转；点开后物件转到左侧继续展示，案例从右侧滑入。 |
| **C Canvas** | Jason Yuan · 排版 | 所有项目、决策和证据都排在一张无限画布上。开场从名字拉远看到全图；点击项目时镜头先拉远、再平移、再推近。带缩略地图。 |
| **D Particles** | Jason Yuan · 编辑式索引 | 左侧是大字号项目索引；名字由几千个粒子组成，会避开光标。悬停某个项目时，粒子重组成该项目的图像；点击后粒子炸开，真实图片飞入成为封面。 |

## v3 · Exhibition（[`demo/v3/index.html`](v3/index.html)）

基于 v2 的 Gallery 继续深化：沉浸式的暖调深灰展厅，像 T 台一样用聚光灯打亮作品，但整体不走暗黑风。案例页仍然使用统一的浅色简约模板。

1. **入口**：名字被一束灯光照亮，左下角是“展览导览”，列出三个展厅、各自的作品数和重点作品。
2. **三个展厅 = 三个分类**：I AI 产品与信任 · II 体验、无障碍与恢复 · III 研究与证据。每个展厅有一道门，门框上写着展厅名，并用不同色温的灯光区分；穿过门时会有一次灯光闪变，表示进入了新的空间。
3. **每次滚动停在一件作品前，像翻页一样**。镜头停下时，侧边卡片会写明分类、项目类型、背景（公司或客户）、我的职责、所处阶段，并提供案例入口。每个展厅的重点作品展板更大，并带有 Featured 标记。
4. **最后一个展厅**：所有展板从身后飞回，按分类钉到一面墙上，所有作品一目了然。
5. **总览板**：三列分类卡片，每张写明类型、背景、职责和阶段，可按分类筛选；下面是“能力 → 对应项目”的对照表，方便招聘方快速了解。
6. 之后是工作方法和联系方式。

## v4 · Gallery Walk（[`demo/v4/index.html`](v4/index.html)）推荐

在 v3 的基础上回到初版 Gallery 的空间布局：去掉展厅门，展板左右交错，整体是暖调深灰加聚光灯。

1. **画廊**：每次滚动（或 ↑↓、轻扫）翻一页，镜头平稳移到下一件作品。停下时侧边卡片说明分类、类型、背景、我的职责和阶段。三个展厅只用悬浮的章节标题区分。
2. **展板**：走完最后一件作品后进入 Canvas 板式。先显示 Canvas 的开场标题；再往下滑，镜头拉远，露出整块按分类排好的展板。之后可以自由拖动、缩放，点击作品放大，再点一次进入案例。展板背景沿用展览的色调。
3. **底线翻页**：展板底部有一条底线。滑到底线后继续往下滑，会出现进度条；滑满即翻页到尾页（工作方法、能力对照、联系方式），不会再出现一次回顾。在尾页顶部往上滑，可以翻回展板。

**性能**：走廊的地面、墙和天花板改用 2D canvas 绘制（与 3D 展板使用同一套透视计算），不再用超大的 3D 图层；光束去掉了模糊滤镜；滚动改为按手势翻页，不再和原生滚动互相拉扯。在没有 GPU 的测试浏览器里，帧率从 v3 的约 3 fps 提升到约 31 fps。

## v5 · 景深与配色（[`demo/v5/index.html`](v5/index.html)）

在 v4 的基础上增加两项：

- **景深虚化**：镜头停在展厅章节时，整个展厅虚化，章节标题、一句说明和作品按钮居中显示；停在某件作品时，只有这件作品清晰，走廊和其他展板都虚化；入口处标题清晰，远处的展板虚化；在展板里点开某件作品时，其他内容同样虚化。镜头一移动，虚化就褪去。
- **四种配色**（右上角切换，也可以在链接后面加 `#dark` / `#light` / `#vivid` / `#aura`）：
  - **Dark**：暖调深灰加聚光灯（v4 的配色）
  - **Light**：日光展厅，暖白墙面，柔和的投光
  - **Vivid**：每个展厅涂一种饱和色（朱红 / 钴蓝 / 明黄），展板背景是钴蓝
  - **Aura**：浅灰底色，每件作品背后有一团珊瑚、橙、黄的柔光渐变，展板和尾页的背景也有缓慢漂移的光晕
