# Next Step · 作品集视觉 Demo

打开 [`demo/index.html`](index.html)（直接用浏览器打开，或在仓库根目录运行 `python3 -m http.server` 后访问 `/demo/`）。

这是一个 **流程 + 风格** 的样板，不是成品：8 个项目只放了关键事实，用来检验每种视觉世界承载真实内容时的样子。

## 核心概念

你的所有项目都在回答同一个问题：**当信息不确定、界面挡路、或日常流程被打断时，人如何走出下一步？**
所以作品集本身也被设计成“会解释自己、会被打断再恢复”的界面：

| 机制 | 来源 | 作用 |
| --- | --- | --- |
| **中断式开场** | Remembering in Motion | 加载到 62% 时故意“中断”，然后显示 “where was I?” 并恢复。三秒内讲清你的主题。 |
| **WHY 面板** | Wildling 的 MIND 面板 | 左下角常驻，实时说明当前页面考虑过哪些布局、最后选了哪个、为什么。 |
| **旅程轨道** | Transfer Coach 的行程进度 | 右侧显示 Boot → Hero → Work → Case → Process → Contact，可点击跳转。 |
| **“尚未证明”章节** | 各仓库的 honest scope 习惯 | 每个案例最后一章写清楚哪些结论还没验证。 |

## Demo 流程

`00 Boot` 中断与恢复 → `01 Hero` → `02 Work` 项目索引 → `03 Case` 案例（从点击位置圆形展开，←/→ 切换，Esc 关闭）→ `04 Process` 四步方法 → `05 Contact` 磁吸按钮。

## 四个视觉世界（底部切换，或按 1–4）

| 世界 | 融合的参考 | 关键体验 |
| --- | --- | --- |
| **1 Departure** | Dennis Snellenberg · Daniel Spatzek | 撑满屏幕的宽体名字（字母悬停时变窄）、技能跑马灯、**翻牌式出发看板**列出项目，悬停时项目图跟随光标、状态重新翻牌。 |
| **2 Mind OS** | Jason Yuan | 极光暗色玻璃质感。**命令栏**可输入关键词或选择三种审阅视角来筛选项目；每个项目是一个窗口，附带 MIND 读数（用户需要 / 设计选择）。⌘K 随时唤起。 |
| **3 Clay Island** | David Heckhoff · Luca | 可拖拽旋转的 **3D 黏土小岛**，每个项目是一个来自它自身世界的物件：水獭、小猫、黑胶、巴士、冰箱、声波、包和钥匙、图表。下方有不依赖 3D 的卡片列表作为备用。 |
| **4 Field Notes** | Queenie · Luca | 方格纸研究墙，三张便利贴写着你关注的三种情境；项目是**可拖拽的证据卡片**，手写批注写着每个项目的关键结论。 |

## 下一步建议

1. 先选主世界：Departure 最适合招聘方快速浏览；Clay Island 记忆点最强。
2. 混合使用：比如 Clay Island 做首页，Departure 看板做 `/work`，Field Notes 做研究类案例页。
3. 把案例页的 `05 Media slots` 换成真实视频、前后对比和原型链接。
